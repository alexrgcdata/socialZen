Offline installation guide

This guide works offline once the project folder is downloaded. It explains how to load SocialZen in Chrome, Edge, or Safari, with the note that the current build is tested first for Chrome and Edge.

Chrome

  1. Unzip the SocialZen folder anywhere you like.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the unzipped project folder.
  5. Pin SocialZen if you want quick access to the popup.

Best first check: Chrome on Windows, because that is the primary test target for this build.

Edge

  1. Unzip the SocialZen folder.
  2. Open edge://extensions.
  3. Enable Developer mode.
  4. Select Load unpacked and pick the project folder.
  5. Open Facebook and confirm the filter is active.

Edge uses the same unpacked-extension flow as Chrome, so setup should feel nearly identical.

Safari

Safari Web Extensions use a different packaging path than Chrome and Edge. For the first demo, treat Safari as a later-step guide rather than the primary install target.

Chrome/Edge first Safari later No build step

If you plan to adapt it for Safari later, keep the source simple and standards-based so the structure can be carried forward.

What you get

SocialZen by Alex Seidler soft-hides emotionally charged political posts on Facebook so the feed feels calmer and easier to browse. The extension is designed to stay small, readable, and easy to edit.

The keyword lists are meant to be editable in the project files, and the extension is intended to be loaded directly from the unzipped folder.
